## What’s new in Upkeep v1.6.1

- Upkeep’s new menu bar icon fills in when Caffeinate is active.
- Caffeinate Settings now has a duration slider and an Until Stopped option.
- Keep Awake With Lid Closed now applies to future Caffeinate sessions after one-time administrator approval.

The release archive supports Apple silicon Macs running macOS 26 or later. The Homebrew package browser uses native tabs on macOS 27.
